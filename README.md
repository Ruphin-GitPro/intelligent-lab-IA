# Aviator Intelligence Lab — BET261

Laboratoire local d'analyse statistique et de simulation (argent fictif).
**Lecture seule** : aucune mise réelle, aucun identifiant ni cookie stocké.

> Avertissement scientifique : aucun programme ne peut prévoir un résultat
> aléatoire à partir des seuls résultats passés. Ce projet sert à comprendre
> les statistiques et à mesurer les risques, pas à promettre des gains.

État : Phase 2-3 (squelette). La documentation complète sera rédigée en Phase 10.
